# Product Overview
## Coach Infrastructure Platform for Runners

---

# 1. Vision

Build the operating system for independent running coaches.

The platform bridges the gap between:
- Athletes who want structured improvement
- Coaches who need professional infrastructure

Instead of competing with Strava, we integrate with it and build the coaching layer on top.

---

# 2. Core Identity

This is NOT:
- A Strava competitor
- A basic fitness tracker
- Another analytics dashboard

This IS:
- Coach Workspace
- Athlete Progress Infrastructure
- Structured Training Ecosystem

---

# 3. Primary Users

## Athletes
- Recreational runners
- 5K / 10K / Half marathon trainees
- Data-driven improvement seekers

## Coaches (Primary Paying Customers)
- Independent running coaches
- Online training providers
- Structured plan creators

---

# 4. Core Product Pillars

## 4.1 Athlete Analytics Engine
- Strava sync
- Activity storage
- Split-level (1km) metrics
- PR detection
- Weekly performance dashboard
- HR and cadence trends

## 4.2 Coach Workspace (Replaces WhatsApp + Sheets)
- Athlete management dashboard
- Structured plan builder
- Weekly training blocks
- Workout prescription
- Adherence tracking
- Athlete progress view

## 4.3 Communication Layer
- Coach ↔ Athlete messaging
- Workout-level feedback
- Session notes
- Performance comments

## 4.4 Billing & Revenue Layer
- Subscription billing
- One-on-one session payments
- Program purchases
- Commission model
- Coach payout tracking

---

# 5. MVP Scope (Phase 1)

## Athlete Side
- Strava OAuth
- Activity sync (last 30 days initially)
- Split storage (1km)
- Dashboard
- PR detection

## Coach Side
- Coach profile creation
- Athlete invitation
- Basic dashboard (view athlete stats)
- Subscription billing
- Commission-based payment model

---

# 6. Phase 2 (Coach OS Expansion)

- Structured plan builder
- Workout scheduling
- Messaging threads
- Session booking calendar
- Diet plan uploads
- Program marketplace (10K Prep, 22K Prep, Beginner, GSC)

---

# 7. Long-Term Vision

- AI-assisted plan suggestions
- Overtraining risk detection
- Corporate wellness integration
- Coach branding tools
- Multi-sport support
- Mobile app ecosystem

---

# 8. Strategic Positioning

"Where coaches build their business, and athletes build structured progress."
